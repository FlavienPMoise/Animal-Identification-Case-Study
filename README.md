K. R. Shrimali, "Transfer Learning for PyTorch Image Classification," *LearnOpenCV*, Jul. 17, 2024. [Online]. Available: https://learnopencv.com/image-classification-using-transfer-learning-in-pytorch/. [Accessed: May 5, 2026].
